# Kiln & Ash – Studio Pottery

A modern and responsive React-based landing page for a pottery studio. The project focuses on creating a clean user interface with interactive components, smooth animations, and a responsive layout that works seamlessly across all devices.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Modern and clean UI
- Responsive navigation menu
- Interactive React components
- Smooth animations and transitions
- Dynamic workshop content loading
- Image gallery section
- Contact form with client-side validation
- Loading skeleton effect
- Scroll reveal animations
- Mobile-friendly hamburger menu

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6)
- HTML5
- CSS3

## 📂 Project Structure

```
kiln-and-ash.html
```

The project is built in a single HTML file using React via CDN along with embedded CSS and JavaScript.

## 📱 Responsive Design

The website is fully responsive and optimized for:

- Desktop
- Tablet
- Mobile Devices
